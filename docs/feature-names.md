# Feature naming

Own-feature messages describe which symbol types support filters and blending without the comparative phrase “as in Animate”. Matching comments and explanatory prose use the same direct descriptions.

File-format interoperability references and required trademark/non-affiliation notices remain intact. Regression tests prevent the retired comparative phrase from returning to production display strings. No version, release workflow, release-stage setting or release hold is changed.

## Shape properties, lines to fills (2026-11-21)

Issue #530 asks for a properties button that turns a selected stroke into a fill. The reference app labels that button "Expand to Fill". That name is not used here. It is another product's name for this action, it is not in the shared names list, and it was not cleared: no register search is treated as a finding that the name is free (unclear means no). The button uses the label this command already has, **Convert Lines to Fills** (`modify.lines_to_fills`, Modify › Shape).
